# Illustrations

Equi uses illustrations **sparingly**.

## When to Use

- Empty states (no holdings, no watchlist items)
- Optional onboarding moments
- Rare error states where a simple icon is not enough

## Style

- **Minimal** — simple shapes, limited palette from brand colors
- **Not childish** — no cartoon characters or playful mascots
- Align with calm, premium SaaS tone

## Avoid

- Stock photo aesthetics in product UI
- Heavy illustrative backgrounds behind data-heavy screens
- Illustrations that compete with charts and tables for attention

## Format

- SVG preferred for crisp scaling
- Store in this folder with descriptive names: `empty-portfolio.svg`
