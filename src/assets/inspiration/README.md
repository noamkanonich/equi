# Inspiration

Place reference screenshots or generated mood images here for UI work.

## Suggested References

Collect (or generate) inspiration for:

- Main dashboard — portfolio summary, key metrics, calm layout
- Portfolio page — holdings table, allocation
- Watchlist — compact list, quick scores
- Stock analysis — score breakdown, fundamentals
- Smart replace — side-by-side comparison, trade-off copy
- Fundamental charts — clean Recharts-style visuals
- AI insight cards — concise summary + positives/risks

## Usage

- Use for **layout, density, and tone** — not pixel-perfect copying
- Prefer light-mode, premium SaaS references over admin panels or trading terminals
- Note source and date in filenames when helpful: `dashboard-ref-2025-01.png`

## Do Not

- Copy competitor branding, logos, or trademarked UI verbatim
- Treat inspiration as final spec — always align with `brand/` and `prompts/design-brief.md`
