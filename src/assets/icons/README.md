# Icons

## Library

Use **lucide-react** as the single icon source unless explicitly approved otherwise.

## Style

- Simple **line icons**
- Consistent **stroke width** (default Lucide stroke is fine)
- Size: typically 16–20px inline, 24px in nav
- Color from theme tokens, not hardcoded hex

## Rules

- Do not mix icon packs (Heroicons, Font Awesome, etc.) without approval
- Mirror directional icons (chevrons, arrows) appropriately in RTL where UX expects it
- Use semantic icons sparingly — clarity over decoration

## Common Icons

| Use | Suggested icon |
|-----|----------------|
| Portfolio | `PieChart`, `Briefcase` |
| Watchlist | `Eye`, `Star` |
| Analysis | `BarChart3`, `LineChart` |
| AI insight | `Sparkles`, `MessageSquare` |
| Settings | `Settings` |
| Alert / watch | `AlertTriangle` |
